COUSIN.EXE — MULTI-PAGE FEEL WITH SMOOTH TRANSITIONS

This version shows one screen at a time. The Next buttons transition to the next screen; it does not display every section as one long scrolling page.

FILES
- index.html
- style.css
- script.js
- photos/

PUT THESE FILES IN photos/ USING EXACT NAMES
1. poovu-main.jpg   - Poovu's main photo
2. poovu-funny.png  - funny reaction sticker
3. poovu-sad.png    - sad reaction sticker
4. animal-cat.jpg
5. animal-llama.jpg
6. animal-duck.jpg
7. animal-cat2.jpg
9. hiba.jpg
10. zaya.jpg
11. radhimaa.mp3 - optional song audio file

RUN
1. Extract the ZIP.
2. Open the extracted cousin-exe-pages folder in VS Code.
3. Add/rename your photos in the photos folder.
4. Install Live Server in VS Code if needed.
5. Right-click index.html > Open with Live Server.

FLOW
Homepage -> Guess That Cousin -> Personality Exposer -> Roast Wheel -> Heart Reveal -> Editors.
Each screen has a Next button; some Next buttons unlock after completing the game. The wheel is intentionally aligned to stop with the Minhaj segment exactly at the top pointer on every spin. The final editors screen shows Hiba and Zaya only.

MUSIC
The audio file is not included. Add a legally obtained/usable audio file named photos/radhimaa.mp3. Public publishing of copyrighted songs may be restricted by the hosting platform.

PUBLICATION
Only publish photos you have permission to share. Files on a public website may be accessible to visitors.
